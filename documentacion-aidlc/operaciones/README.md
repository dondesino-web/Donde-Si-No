# Operaciones y Monitoreo (Índice de Fase)

## Definición del documento

- **Para qué sirve:** centraliza las políticas de observabilidad, SLAs, procedimientos ante incidentes y análisis post-mortem.
- **Cuándo se crea o actualiza:** en la fase de Operaciones.
- **Qué debe contener:** estado de monitoreo, SLAs, manuales y post-mortems.
